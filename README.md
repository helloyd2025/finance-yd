# 금융 데이터 신용평가 파이프라인

## 개요
- 기업 신용평가 합성 데이터(`기업신용평가정보_합성데이터.csv`)를 로드하고 전처리한 뒤, 랜덤 포레스트 기반의 예측 파이프라인을 실행합니다.
- 두 가지 타겟:
  - `기업신용평가등급(구간화)` : 1~10 구간의 등급 분류
  - `모형개발용Performance(향후1년내부도여부)` : 향후 1년 내 부도 여부(0/1)

- `use_hybrid` 설정에 따라 규칙 기반 점수와 ML 예측을 결합한 하이브리드 방식 또는 ML 단독 방식을 사용할 수 있습니다.
- 결과는 콘솔 로그와 CSV(`predictions_80.csv`)로 확인할 수 있으며, CSV에는 원본 데이터 행 번호가 인덱스로 포함됩니다.

## 디렉터리 구성 (주요 파일)
- `load_dataframe.py` : 비표준 CSV 헤더 처리 및 데이터 로더
- `random_forest_pipeline.py` : 전처리, 학습/예측, 평가, 결과 저장
- `hyperparameter_tuning.py` : 랜덤 포레스트 하이퍼파라미터 탐색 도구
- `predictions_80.csv` : `run_pipeline_predict80` 실행 결과 (20% 학습, 80% 예측)

## 데이터 요구사항
- 입력 CSV는 UTF-8 인코딩, 쉼표 구분을 권장합니다.
- 헤더가 복잡한 경우에도 `load_by_data_fields()`가 첫 데이터 행의 필드 수를 기준으로 컬럼명을 재구성합니다.
- 마지막 두 컬럼이 타겟 컬럼이며, 수치형 특성은 자동으로 캐스팅됩니다. 문자열 특성은 자동으로 제외됩니다.

## 사용 방법
### 1. 기본 파이프라인 실행 (ML 단독)
```bash
python random_forest_pipeline.py
```
- 기본값 `use_hybrid=False`로 20% 학습, 80% 예측을 수행합니다.
- 콘솔에 각 타겟의 정확도·F1·Recall이 출력되고, `predictions_80.csv`에 결과가 저장됩니다.

### 2. 하이브리드 방식 비교
```bash
python random_forest_pipeline.py --use-hybrid
```
또는 스크립트에서 `run_pipeline_predict80(use_hybrid=True)`로 호출하세요.
- 결과 CSV에 ML 단독 추정치(`*_ml_only`)와 하이브리드 추정치가 모두 포함됩니다.

### 3. 다른 CSV로 실행
```python
run_pipeline_predict80(csv_path="다른파일.csv", out_path="output.csv", use_hybrid=True)
```

### 4. 종합 학습/평가 루틴
`run_pipeline()`은 데이터 전처리 후 train/test 분할로 두 타겟을 순차 평가하고, 샘플 비교 및 리포트를 출력합니다.

## 출력물 설명
- `predictions_80.csv`
  - 인덱스 `원본CSV행번호` : 원본 CSV에서의 실제 행 번호(헤더 기준 +2)
  - 열 구성 (예시, 하이브리드 사용 시)
    - `pred_기업신용평가등급(구간화)` : 최종 예측 (ML 또는 하이브리드)
    - `true_기업신용평가등급(구간화)` : 실제 값
    - `pred_기업신용평가등급(구간화)_ml_only` : ML 단독 예측 (하이브리드 모드에서만 존재)
    - 타겟2도 동일 패턴
  - 타겟1·타겟2 중 한쪽에서만 예측된 행은 다른 타겟의 열이 `NaN`으로 남습니다(합집합 조인).
- 콘솔 로그:
  - 데이터 로드 상세, 학습/예측 샘플 수
  - 정확도, F1-score, Recall
  - 샘플 예측 결과 상위 10개

## 유틸리티 스크립트
- `analyze_features.py`
  - 특성 중요도, 상관관계, 타겟 분포 등을 분석하는 보조 도구
  - 독립 실행 시 `python analyze_features.py`
- `hyperparameter_tuning.py`
  - 랜덤 포레스트 하이퍼파라미터 탐색(예: Grid/Random Search)을 위한 기반 코드

## 개발 메모
- 타겟별로 독립적인 학습/예측 파이프라인을 실행하며, 분할 인덱스가 서로 다를 수 있습니다.
- `random_forest_pipeline.py`는 학습용으로 분할된 데이터를 제외한 예측 행만 CSV에 기록합니다.
- 합집합 방식으로 결과를 병합하기 때문에 일부 열에 `NaN`이 있을 수 있습니다. 이 경우 해당 타겟 모델에서 예측하지 않은 행입니다.
- `기업신용평가등급(구간화)` 컬럼은 특성(X)에 포함되어 타겟2 학습에 활용됩니다.

## 추가 개선 아이디어
- 하이퍼파라미터 튜닝 자동화 (`hyperparameter_tuning.py` 활용)
- 클래스 불균형 대응 (예: SMOTE, class weight)
- 모델 성능 비교(다른 알고리즘, AutoML 도입)
- 파이프라인을 모듈화하여 CLI 인자 처리 또는 REST API 연동
